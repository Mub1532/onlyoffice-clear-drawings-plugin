# Only Office Clear Drawings Plugin

Simple plugin to allow onlyoffice to clear all drawings, shows in the draw tab.

Removes every pen / highlighter drawing in the document.

## Install
- Download `clear-drawings.zip` from the latest release and unzip it in the onlyoffice plugin folder location.

## Usage

- Pressing the main part of the button, clears ALL annotations - pen and highlighter.
- Also a dropdown to clear either only highlighted or pen annotations

Notes:
- Plugin Tested on Only Office 10. Works will all types, Word, Powerpoint, Excel etc or equivalents eg odt, etc.
- Drawing based highlight and actual in the document highlighting is different, this plugin is for drawing based.
